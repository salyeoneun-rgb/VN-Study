# 📚 VN Study Journal

> 비주얼 노벨을 통해 일본어를 공부하는 사람들을 위한 개인 학습 기록장

---

# 📖 프로젝트 소개

**VN Study Journal**은 비주얼 노벨(Visual Novel)을 읽으며 일본어를 공부하는 학습자를 위한 개인 웹 애플리케이션입니다.

이 프로젝트는 번역기나 AI를 이용해 정답을 알려주는 것을 목표로 하지 않습니다.

대신, **스스로 읽고, 고민하고, 틀리고, 다시 이해하는 과정**을 기록하여 자신의 학습 데이터를 쌓아가는 것을 목표로 합니다.

하나의 문장은 단순히 읽고 지나가는 텍스트가 아니라,

- 어떤 단어를 몰랐는지
- 어떤 문법에서 막혔는지
- 왜 해석을 틀렸는지
- 어떻게 이해하게 되었는지

를 기록하는 하나의 학습 기록이 됩니다.

---

# 🎯 개발 목적

일본어 공부를 하다 보면 같은 단어를 여러 번 찾아보고,

같은 문법을 반복해서 틀리며,

예전에 읽었던 문장을 다시 봤을 때도 기억나지 않는 경우가 많습니다.

기존 메모 앱이나 노트 앱으로도 기록은 가능하지만,

비주얼 노벨 학습에 특화된 기능은 부족했습니다.

그래서 다음과 같은 기능을 가진 전용 학습 웹앱을 만들고자 합니다.

- 작품별 관리
- 챕터별 관리
- 문장별 기록
- 단어 관리
- 문법 관리
- 오답 노트
- 학습 통계
- 복습 관리

---

# ✨ 주요 기능

## 📚 작품 관리

- 작품 생성
- 작품 수정 및 삭제
- 챕터 관리
- 작품별 학습 진행률 확인

---

## 📝 문장 기록

각 문장마다 다음 내용을 기록할 수 있습니다.

- 원문
- 후리가나(요미가나)
- 직역
- 의역
- 개인 메모

---

## 📖 단어 관리

모르는 단어를 별도로 저장합니다.

각 단어에는 다음 정보를 기록할 수 있습니다.

- 단어
- 뜻
- JLPT 급수
- 품사
- 메모

또한 하나의 단어가 여러 문장에서 등장하면 자동으로 연결됩니다.

---

## 📘 문법 관리

문법을 별도의 데이터베이스로 관리합니다.

예시

- ～わけではない
- ～ことになる
- ～ばかり

문법은 여러 문장에서 공통으로 사용할 수 있습니다.

---

## ❌ 오답 노트

가장 중요한 기능입니다.

단순히 정답을 적는 것이 아니라

- 내가 처음 어떻게 해석했는지
- 실제 의미는 무엇이었는지
- 왜 틀렸는지

를 기록하여 같은 실수를 반복하지 않도록 합니다.

---

# 🚫 이 프로젝트가 지향하지 않는 것

이 프로젝트는

- AI 번역기
- 자동 해석 프로그램
- 일본어 사전

을 만드는 것이 아닙니다.

사전을 찾아보고,

직접 해석하고,

틀린 이유를 기록하며,

자신만의 일본어 학습 데이터베이스를 만들어가는 것이 목표입니다.
